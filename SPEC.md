# Project: New Chromium-based browser (built with Electron)

Niche: browser for coders

Requirements:
- Privacy: block trackers/ads by default
- Performance: lower RAM use, tab suspension
- UI/UX: vertical tabs, split view, workspaces
- Built-in: developer toolkit (JSON viewer, API tester, notes), AI sidebar

Stack: Electron + JavaScript (React later)
Rule: build one small feature at a time, keep code simple and commented.
